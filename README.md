# 52-Card Deck Sandbox (HTML5)

A free-play card table in your browser. A shuffled 52-card deck sits face down in the top-left corner of a green felt table. Drag cards out, flip them, and arrange them however you like. There are no rules.

## Controls

| Action | Mouse | Touch |
| --- | --- | --- |
| Move a card | Left-click and drag | Drag |
| Flip a card | Right-click | Tap |
| Start over | **New shuffled deck** button | Same |

The card you grab comes to the top of the pile.

## Play locally

Open `index.html` in a browser. It's one file with no dependencies.

## Deploy

`.github/workflows/pages.yml` publishes the page to GitHub Pages on every push to `main`. In the repo, under **Settings → Pages**, set **Source** to **GitHub Actions**.
